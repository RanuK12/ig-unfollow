# 🚀 Guía de Inicio Rápido - ig-unfollow v3.0

**Comienza en 2 minutos. Usa de forma segura.**

---

## ⚡ Opción 1: Bookmarklet (RECOMENDADO)

### Paso 1: Copiar código
1. Abre [bookmarklet.html](bookmarklet.html) en Chrome/Firefox/Safari
2. Haz clic en **"Copiar Código"** (se copia automáticamente al portapapeles)

### Paso 2: Crear bookmark
1. **Chrome/Edge:**
   - Click derecho en la barra de favoritos
   - Selecciona "Agregar página"
   - Nombre: `IG Unfollow`
   - Pega el código en el campo URL
   - Guarda ✅

2. **Firefox:**
   - Ctrl+Shift+D (o Cmd+Shift+D en Mac)
   - Nombre: `IG Unfollow`
   - Ubica: `Toolbar`
   - Pega el código en "Dirección"
   - Guarda ✅

3. **Safari:**
   - Menú → Favoritos → Agregar bookmark
   - Nombre: `IG Unfollow`
   - Dirección: pega el código
   - Guarda ✅

### Paso 3: Usar
1. Ve a [instagram.com](https://instagram.com)
2. **Asegúrate de estar logueado** ⚠️
3. Haz clic en tu bookmark `IG Unfollow`
4. ¡El panel aparecerá!

## 💻 Opción 2: Consola (Inmediata)

### Paso 1: Abrir DevTools
1. Ve a [instagram.com](https://instagram.com)
2. **Asegúrate de estar logueado** ⚠️
3. Presiona:
   - **Windows/Linux:** F12
   - **Mac:** Cmd + Option + I

### Paso 2: Ir a Console
- Haz clic en la pestaña **Console**

### Paso 3: Pegar código
1. Abre [COPY_CODE.html](COPY_CODE.html)
2. Copia TODO el código en el área gris
3. Vuelve a DevTools → Console
4. Pega el código
5. Presiona **Enter** ✅

## 🛡️ IMPORTANTE: 5 Reglas de Seguridad

**Léelas. En serio.**

### 1️⃣ Comienza pequeño
- Primera sesión: **máximo 5 unfollows**
- Espera 24 horas
- Monitorea tu cuenta

### 2️⃣ No lo uses todos los días
- Máximo 1-2 veces por semana
- Espera 24-48 horas entre sesiones
- El script lo impone automáticamente

### 3️⃣ Vigila el indicador de riesgo
- **Verde/Amarillo:** OK
- **Naranja:** Sé cuidadoso
- **Rojo:** DETÉN INMEDIATAMENTE

### 4️⃣ Si ves "Challenge Required"
- Instagram te pide verificación
- Verifica (SMS, email, app)
- **PARA la herramienta**
- Espera 24 horas mínimo antes de reintenta

### 5️⃣ Nunca excedas los límites
```
Máximo por día:     100 unfollows
Máximo por sesión:  40 unfollows
Máximo duración:    2 horas
Máximo sin pausa:   8 unfollows → pausa 3-7 min
```

## 🤔 Preguntas Comunes

### P: ¿Es seguro?
R: Violas TOS de Instagram. Riesgo de bloqueo. Usa bajo tu riesgo.

### P: ¿Cuándo será desiguiendo?
R: 10-18 segundos entre cada uno, con pausa de 3-7 min cada 8.

### P: ¿Se guarda mi contraseña?
R: NO. Usa cookies de sesión. Sin acceso a tu contraseña.

### P: ¿Funciona en móvil?
R: Parcialmente. Chrome móvil OK. Safari móvil: difícil.

### P: ¿Puedo pausar?
R: SÍ. Botón [Pausa]. Retoma cuando quieras.

### P: ¿Qué pasa si cierro la pestaña?
R: Se detiene inmediatamente. Reinicia cuando quieras.

### P: ¿Puedo proteger a alguien?
R: SÍ. Pestaña "Protegidos" o haz click en 🛡️ en cualquier usuario.

### P: ¿De dónde obtiene los datos?
R: API oficial de Instagram (unofficial). No hay base de datos externa.

### P: ¿Alguien puede ver que lo usé?
R: NO. Es 100% local en tu navegador. Sin logs del servidor.

## 🔧 Solución de Problemas

### "No logueado" / "Sin CSRF token"
```
1. Ve a instagram.com
2. Asegúrate de estar logueado
3. Cierra otras pestañas de Instagram
4. Recarga la página
5. Intenta de nuevo
```

### "Rate Limited" (Error 429)
```
1. Instagram te pidió que esperes
2. Pausa el script (botón [Pausa])
3. Espera 5-10 minutos
4. Resume
```

### Panel congelado / Lento
```
1. Revisa tu conexión de internet
2. Cierra otras pestañas
3. Reinicia el script
4. Intenta en modo Incógnito
```

### Interfaz no aparece
```
1. F5 para recargar instagram.com
2. Asegúrate de estar logueado
3. Abre DevTools (F12) y revisa errors (console)
4. Intenta de nuevo
```
